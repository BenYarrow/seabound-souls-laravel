# Rider Contributor Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let invited "Rider" contributors log in, build spot guides with a map-click coordinate picker, submit them for review, and let the owner preview, approve, and publish — all in-panel.

**Architecture:** A two-role model (`owner` / `rider`) on `users`, enforced by Laravel Policies + Filament resource scoping. Spot guides gain an author (`user_id`) and a review lifecycle (`draft → in_review → changes_requested → approved`) driven by explicit model methods and Filament header actions. Media is owner-scoped so Riders never see house media. Coordinates are captured via a reusable custom Filament field backed by a Mapbox modal. Unpublished guides render on the real public page only for the owner or the guide's author.

**Tech Stack:** Laravel 12, Filament v3.3, Livewire v3, Inertia v2 + React 19, Spatie Media Library v11, Mapbox GL, PHPUnit (in-memory SQLite).

    /**

     * design (no lock), so this only advances the status + stamps the time.

    public function submitForReview(): void
    {

    /**

    public function publish(): void

<?php

// A UI-only Filament field that opens a Mapbox modal; clicking the map writes the
// chosen coordinates into two sibling fields (latitude/longitude) in the same
// form container — so it works standalone AND inside repeater rows. It stores
// nothing of its own (dehydrated(false)).

namespace App\Filament\Forms\Components;

use Filament\Forms\Components\Field;

class MapCoordinatePicker extends Field
{
    protected string $view = 'filament.forms.components.map-coordinate-picker';

    protected string $latitudeField = 'latitude';

    protected string $longitudeField = 'longitude';

    protected function setUp(): void
    {
        parent::setUp();
        // Purely a control — never persisted or hydrated.
        $this->dehydrated(false);
    }

    /** Relative name of the latitude sibling field (default 'latitude'). */
    public function latitudeField(string $name): static
    {
        $this->latitudeField = $name;

        return $this;
    }

    /** Relative name of the longitude sibling field (default 'longitude'). */
    public function longitudeField(string $name): static
    {
        $this->longitudeField = $name;

        return $this;
    }

    /** Absolute Livewire state path of the latitude sibling. */
    public function getLatitudePath(): string
    {
        return $this->resolveSiblingPath($this->latitudeField);
    }

    /** Absolute Livewire state path of the longitude sibling. */
    public function getLongitudePath(): string
    {
        return $this->resolveSiblingPath($this->longitudeField);
    }

    protected function resolveSiblingPath(string $name): string
    {
        return self::siblingPathFor($this->getStatePath(), $name);
    }

    /**
     * Siblings share this field's parent container path. Strip the leaf segment
     * of $statePath and append the sibling's name — handles both top-level forms
     * and nested repeater rows (paths like data.repeater.uuid.field). Pure and
     * static so the derivation is unit-testable without a mounted form.
     */
    public static function siblingPathFor(string $statePath, string $name): string
    {
        $lastDot = strrpos($statePath, '.');
        $parent = $lastDot === false ? '' : substr($statePath, 0, $lastDot);

        return $parent === '' ? $name : $parent . '.' . $name;
    }
}

## Notes / deviations from the spec

- **Notifications** are delivered as Laravel `Notification` classes whose `toDatabase()` returns a Filament database message (`FilamentNotification::...->getDatabaseMessage()`). This satisfies both goals from the spec: the Filament bell shows them now, and email is a pure addition later (`via()` gains `'mail'`, add a `toMail()`). The single extension point is each notification class.
- **Mapbox in Filament** is loaded from the Mapbox CDN inside the picker modal (lazy, once), rather than bundled into the admin theme — the smallest change that avoids new Vite entry wiring for the admin panel. It requires internet in the admin (already true for the public maps). If offline-admin ever matters, bundle `mapbox-gl` into the Filament theme instead.
- **Countries for riders:** riders don't get the Countries nav item (owner-only via `CountryPolicy::viewAny`), but can add a missing country inline from the guide's country select (`createOptionForm`), matching "create if needed, can't edit/delete existing".
