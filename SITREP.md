# Situation Report — Seabound Souls (Laravel)

Personal project (not IFP). A Laravel 12 / Inertia / React / Filament rebuild of the original Next.js 15 + Sanity windsurfing destination guide, being polished at a relaxed pace toward launch and held to Ben's IFP working standard (TDD, dark mode, responsive, documented code). See `CLAUDE.md` → "Working standard".

## Right now
- **Pull production DB to local** — `php artisan db:pull-from-production` overwrites the local dev DB with a fresh read-only copy of prod (Laravel Cloud / Neon, DB `main`, Postgres 17), so local dev/debug runs on realistic content (prod: 7 guides / 75 media vs local 3 / 14). Guarded (local-env-only, destination-must-be-local, `pg_dump` ≥ server, confirm-before-wipe), read-only on prod. Needs `PROD_DB_*` in `.env` + PG17 client tools. DB-only v1 (R2 media not pulled; `--with-media` is a follow-up). Suite **146 tests, 868 assertions**. See [2026-07-11-pull-production-db](docs/history/2026-07-11-pull-production-db.md). **Rotate the prod DB password** (shared in chat during setup).
- **Related spot guides slider** — a closing "More Spots in {Country/Continent}" section on every spot-guide page: a full-bleed, one-slide-per-view Swiper of *other* guides, cascading same-country → same-continent → hidden. Ordered featured-first then gustiest-this-month via a shared `SpotGuide::sortByGustiestThisMonth()` (extracted from `DestinationController`, so both pages share one tested ranking). Card = full-bleed image + Knewave title + intro snippet + wind/direction badges + "Explore →", the whole card an Inertia `<Link>`; nav arrows/dots (and the Swiper modules) only render when there's more than one slide. A small **`Same country` / `Same continent`** eyebrow (#30) labels the grouping basis so a continent fallback (e.g. Langebaan → Dahab, both Africa) doesn't imply false proximity. Suite **133 tests, 853 assertions**. See [2026-07-11-related-spot-guides-slider](docs/history/2026-07-11-related-spot-guides-slider.md).
- **Spot-guide weather section light theme** — `SpotGuideStatistics` was still the pre-#24 dark clone; mirrored the destinations weather light theme (pale-teal `bg-primary-lightest` section, white filter bar + white chart cards, dark-on-light axes/grid/text, white tooltips, light react-select). Bar colours unchanged. Frontend-only. See [2026-07-10-spotguide-weather-light](docs/history/2026-07-10-spotguide-weather-light.md).
- **Spot-guide quick-nav** — a sticky, content-aware in-page nav on spot-guide pages: a pure helper (`buildSpotGuideSections`, Vitest-tested) lists only the sections a guide has (DOM order, Content Builder excluded); `SpotGuideNav` renders them as a sticky bar (`top:0`, white/orange/`primary`-active) that smooth-scrolls on click and highlights the active section via a rAF-throttled scroll listener; mobile = swipeable chip row. Each section got an `id` + `scroll-mt-14`. **Closes the 3-part featured/content brainstorm (A #25, B #26, C).** Frontend-only. Suite: JS 13/13, PHP unaffected. Note: the headless preview dispatches no scroll/IO events, so smooth-scroll + active-highlight are inspection-verified — eyeball on the real site. See [2026-07-10-spot-guide-quicknav](docs/history/2026-07-10-spot-guide-quicknav.md).
- **List-content blocks + homepage content-managed** — the `list_content_blogs` / `list_content_spot_guides` builder blocks now work (was a Filament crash — an empty `->relationship('','title')`; now an options Select storing IDs). Hand-pick entries + editable heading / "View all" URL + text; resolved server-side (published-only, authored order) in the shared `ResolvesContentBlockMedia` trait — zero controller changes — and rendered via the existing `FeaturedGrid`. The **homepage is now content-managed**: the hardcoded "6 latest / 3 latest" grids are gone; featured/blog sections come from list blocks on the home Page's content builder. Bundled: `/destinations` now ranks by **gusts** (not wind) for the current month. Suite **124 tests, 764 assertions**. Sub-project **B** of three (A shipped #25; **C — spot-guide quick-nav — still to do**). See [2026-07-10-list-content-blocks](docs/history/2026-07-10-list-content-blocks.md). **Owner (post-deploy):** add the list blocks to the home Page on Cloud, or the homepage shows no featured/blog grids.
- **Featured flag + standout (blogs & spot guides)** — an in-app "Featured" toggle (Filament General tab + quick-toggle list column) on both blogs and spot guides, enforced single-per-type at the model layer (`HasSingleFeatured` trait). Each listing shows the flagged item as a standout hero via a shared `FeaturedHero`: the blog index hero is now flag-driven (page 1 only, excluded from the grid) and `/destinations` gained a featured hero between the intro and map (the guide stays in its continent grid). **No fallback** — nothing flagged → no hero. Sub-project **A** of three (B: list-content blocks; C: spot-guide quick-nav — both still to do). Live visual pass caught + fixed a crash: the blog hero/pagination read `blogs.meta.*` but the Laravel paginator is flat (`current_page`/`last_page` top-level, no `meta`). **Also folded into this PR: relevance-ordered destination listings** — continents render Europe→Africa→rest (fixed priority), and guides within a continent are ranked windiest-first using this year's reading for the current month (re-ranks per request as the month turns; a site-voice note explains it). Suite **122 tests, 752 assertions**. See [2026-07-10-featured-flag-standout](docs/history/2026-07-10-featured-flag-standout.md).
- **Destinations light theme + generated chart palette** — the `/destinations` Mapbox globe and Wind & Weather charts were softened from near-black to a calm light treatment (user feedback: dark felt "aggressive"). Map → `light-v11` + pale atmosphere; the weather zone is a distinct pale-teal (`bg-primary-lightest`) band with a white filter strip + white chart cards, all dark-on-light. The finite 16-colour chart palette is replaced by a **golden-angle HSL generator** (`hsl(H,48%,48%)`, muted, distinct, never runs out) — so new spot guides auto-colour. Stood up **Vitest** (first JS test runner; standalone config, `npm run test:js`) and TDD'd the palette helper. Single-spot `chartColors` trio untouched (follow-up to match). Suites: JS 7/7, PHP **108 tests, 634 assertions**. See [2026-07-10-destinations-light-theme](docs/history/2026-07-10-destinations-light-theme.md).

Suite **94 tests, 505 assertions**; `composer audit` clear of high/medium (4 low dev-only remain).

Remaining pre-launch: 2FA (deferred) + production-env checklist.

All prior SQLite content migrated across intact via a one-off `db:import-from-sqlite` command (FK-safe order, PKs preserved, sequences reset). Test suite stays on in-memory SQLite for speed (Postgres CI job is the parity mitigation). Suite **96 tests, 509 assertions**.
